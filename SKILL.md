# No Slop

Make writing sound like a sharp human wrote it, not an AI. Two ways this gets used:

1. **Clean mode.** The user pastes text and adds /no-slop. Rewrite only what breaks the rules below. Keep everything else exactly as they wrote it.
2. **Write mode.** The user asks you to write something (an email, a LinkedIn post, a message, a bio) and adds /no-slop. Write it following every rule below from the first draft.

If it is unclear which mode applies, text pasted in the message means clean mode; a request with no text to fix means write mode.

## The ban list

Never use any of these, in any form (plural, past tense, "-ing", hyphenated or not). The right-hand column gives plain alternatives. Pick whichever fits the sentence, or rewrite the sentence so the word is not needed. Deleting is often the best fix.

| Banned | Say instead |
|---|---|
| game-changer, game changing | big, major, or say what actually changed |
| unlock | get, open up, give you, make possible |
| unleash | use, let loose, start |
| elevate | improve, raise, lift |
| empower | let, help, give (someone) the means to |
| leverage (as a verb) | use, build on |
| harness | use, put to work |
| delve | look at, dig into, go through |
| dive in, deep dive | get started, a close look, a detailed look |
| seamless | smooth, easy, without a hitch |
| robust | strong, solid, reliable |
| holistic | whole, complete, all-round |
| transformative | big, major, or describe the actual change |
| revolutionize | change, overhaul, rethink |
| cutting-edge | new, latest, modern |
| innovative | new, or say what is new about it |
| synergy | working together, fit |
| streamline | simplify, speed up, cut steps from |
| skyrocket | jump, climb fast, shoot up |
| supercharge | boost, speed up |
| next level, level up | better, improve, step up |
| tapestry | mix, blend |
| realm | area, field, world |
| landscape (used as a metaphor) | market, field, situation |
| journey (used as a metaphor) | process, path, experience, time |
| paradigm | model, approach, way of thinking |
| "the power of X" | "why X works", or just "X" |
| "in today's world", "in the digital age" | now, today, or delete it |

**Literal uses are fine.** "Unlock the door", "a mountain landscape", "a long train journey", "financial leverage" (the noun) are not slop. Only the buzzword or metaphor use is banned.

## Banned structures

Rewrite these into a plain, direct statement:

- **The "not X, it's Y" reframe.** "It's not about the money, it's about the freedom." Also "This isn't just a tool, it's a..." and every variation. Fix: state Y directly. "The real win is freedom."
- **Rhetorical question openers.** "Have you ever...", "What if I told you...", "Imagine if...". Fix: open with the point itself.
- **Drama lines.** "Here's the thing", "Here's the kicker", "Let that sink in", "Read that again". Fix: delete them.
- **Wrap-up clichés.** "In conclusion", "At the end of the day". Fix: delete, or just say the conclusion.

## Banned filler hedges

Delete these when they add nothing: **somewhat, potentially, arguably, essentially, basically.** Keep one only if removing it would make the sentence untrue.

## Banned punctuation

No em dashes (—) or en dashes (–), anywhere. Use a comma, a full stop, a colon, or brackets instead. Normal hyphens inside words ("follow-up", "two-week") are fine.

## Don't make things up

- Never invent facts, numbers, statistics, studies, results, client stories or personal experiences to make the text sound more convincing.
- In clean mode, never add new claims. Only reword what is already there.
- In write mode, if a detail you need is missing (a date, a price, a name), leave a clear placeholder like [date] rather than guessing.

## How to write instead

Write like a sharp practitioner: plain verbs, concrete nouns, definite claims, and a mix of short and longer sentences. Say the thing directly.

## Rules for clean mode

- Keep the writer's meaning, tone, and roughly the same length. This is an edit, not a rewrite.
- Leave untouched: names, numbers, dates, links, quotes, greetings, sign-offs, and formatting (line breaks, bullets, paragraphs).
- If a replacement makes a sentence clumsy, rewrite that one sentence so it reads naturally. Don't force a synonym in.
- If the text is already clean, say so and return it unchanged.

## Final check (do this before answering)

Scan your output one more time for every banned word, structure, hedge and dash above, including the plural and "-ing" forms. Fix anything that slipped through.

## What to send back

1. The finished text first, complete and ready to copy. No intro line before it.
2. Then, in clean mode only, a short "What I changed" list: one line per change, like `"game-changer" → "big shift"`. Group repeats. Keep it under about 8 lines. Skip this list if nothing changed.

Nothing else. No commentary on the writing, no offers to do more.
