# no-slop

A Claude skill by Grounded Labs that strips "AI slop" out of your writing: the buzzwords, cliché sentences and filler that make text read as AI-written.

## Use it

- Paste any text and add `/no-slop`. You get the cleaned text back, plus a short list of what changed.
- Or ask for something new ("write an email to Sarah booking a call Tuesday /no-slop") and it's written slop-free from the start.

## Install

**Claude Code:** paste this line into Claude Code.

```
Install the no-slop skill: download https://raw.githubusercontent.com/grounded-labs-org/no-slop/88f2eef9ddae5488fb2bd390d18649aa943e4a5a/SKILL.md and save it as ~/.claude/skills/no-slop/SKILL.md, then tell me it's ready.
```

**Claude app (claude.ai, desktop, mobile):** copy the text in [claude-app-instructions.txt](claude-app-instructions.txt) and paste it into Settings, then Profile, in the personal preferences box. Then type "no slop" or `/no-slop` in any chat.

The full rules live in [SKILL.md](SKILL.md).

## Why the install link has a long code in it

The link points at one fixed, reviewed version of the skill. Nobody can change what it downloads, not even us, so what you install is exactly what was published. When a new version comes out, this page will show a new link.
